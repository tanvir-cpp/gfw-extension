# GET TO F*CKING WORK (GFW.EXT)

An open-source, brutalist Chrome extension that cuts the bullshit. Blocks distracting sites, enforces strict focus hours, and stops you from wasting your life online.

![Open Source](https://img.shields.io/badge/Open_Source-100%25_LOCAL-FF3333?style=for-the-badge)
![License MIT](https://img.shields.io/badge/License-MIT-black?style=for-the-badge)

## FEATURES_

- **NUCLEAR MODE**: An unbreakable one-hour lockdown. Once engaged, there is no pause button, no bypass, and no way out until the timer hits zero. Pure enforced isolation.
- **FOCUS SCHEDULE**: Set your exact working hours. The blocklist automatically activates when you're supposed to be working, and quietly disengages when you're done.
- **DATA & STATS**: Raw telemetry on your failures. See exactly how many times you tried to visit a blocked site today, your all-time block count, and your current focus streak.
- **DYNAMIC PRESETS**: Stop typing URLs manually. Instantly block entire categories—Social Media, Streaming, News, and Messaging—with a single click in the dashboard.

## INSTALL_

1. Clone this repository:
   ```bash
   git clone https://github.com/tanvir-cpp/gfw-extension.git
   ```
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer Mode** using the toggle switch in the top right corner.
4. Click **Load unpacked** and select the `gfw-extension` directory from the cloned repo.

## TECH STACK_

- **Manifest V3** compliant.
- **Service Workers** for background alarm and schedule tracking.
- **Vanilla JS/HTML/CSS** with a brutalist, dark glassmorphism design system.
- Completely offline, no tracking, no telemetry.
